# Foundations

Foundational topics explain how to reason about an algorithm before choosing a
specific data structure or technique.

Planned pages cover how work and memory grow with input size, how to prove an
algorithm remains correct, how nested function calls use memory, how to avoid
integer overflow, and how integers are represented as bits. Add a page when a
topic can be explained with concrete examples and linked to solved problems.

## Available topics

- [Integer digit processing](integer-digits/) explains how to remove decimal
  digits one at a time, reverse them safely, and check whether a number reads
  the same in both directions.
