# Foundations

Foundational topics explain how to reason about an algorithm before choosing a
specific data structure or technique.

Planned pages cover asymptotic and amortized complexity, correctness
invariants, recursion, integer safety, and bitwise reasoning. Add a page when a
topic can be illustrated with concrete examples and linked to solved problems.

## Available topics

- [Integer digit processing](integer-digits/) explains decimal extraction,
  reversal invariants, overflow checks, and palindrome recognition.
