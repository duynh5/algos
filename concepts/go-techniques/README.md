# Go Techniques

This section covers Go-specific choices that make algorithm solutions easy to
read, efficient enough for the input limits, and compatible with online judges.

Planned pages will explain:

- reading and writing large inputs efficiently;
- running many test cases through the same test code;
- defining a custom sort order;
- using Go's `container/heap` priority queue;
- writing reusable structures with type parameters;
- replacing deeply nested function calls with a loop and an explicit stack;
- understanding when growing or slicing a slice allocates or retains memory.
