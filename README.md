# Software Engineering Study Guide

This repository is an evidence-based study guide for algorithms, backend software engineering, and senior frontend interview preparation.

## Start here

- For coding interviews, use the [DSA curriculum](dsa/README.md).
- For backend or full-stack depth, use the [backend extension](backend/README.md).
- For senior frontend interviews, use the [frontend curriculum](frontend/README.md).

## Repository map

- `dsa/` owns algorithms, data structures, coding-interview study, the active workbench, and the problem archive.
- `frontend/` owns the frontend interview outline and capstone evidence.
- `backend/` owns backend lessons and executable examples, plus the evolving Order API lab.
- `CONCEPTS_STANDARDS.md` owns the shared concept-study contract.
- `REFERENCE_LINKS.md` holds long shared source and file targets.

Reading is not completion. Each active path requires code, tests, failure cases, explanations, and reviewable evidence.
