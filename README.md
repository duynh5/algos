# Software Engineering Study Guide

This repository is an evidence-based study guide for algorithms and
web software engineering. It prioritizes frontend employment, extends
into full-stack engineering, and retains deep backend material for
roles or systems that require it.

## Start here

- For a senior frontend job search, begin with the
  [one-week preparation plan](SENIOR_FRONTEND_JOB_PREP_PLAN.md).
- For frontend and general web-engineering study, use the
  [frontend curriculum](web-engineering/frontend/README.md).
- For coding interviews, use the [DSA curriculum](dsa/README.md).
- For backend or full-stack depth, use the
  [backend extension](web-engineering/backend/README.md).

## Repository map

- `dsa/` owns algorithms, data structures, coding-interview study,
  the active workbench, and the problem archive.
- `web-engineering/frontend/CONCEPTS.md` owns active frontend lessons.
- `web-engineering/backend/` owns backend lessons and executable
  examples, plus the evolving Order API lab.
- `CONCEPTS_STANDARDS.md` owns the shared concept-study contract.
- `REFERENCE_LINKS.md` holds long shared source and file targets.

Reading is not completion. Each active path requires code, tests,
failure cases, explanations, and reviewable evidence.
