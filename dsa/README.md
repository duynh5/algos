# Data Structures and Algorithms

This domain contains the reusable guide, coding-interview plan,
active exercise, and standalone problem archive for data structures
and algorithms (DSA).

## Learning path

1. Use the [concept guide](CONCEPTS.md) to learn reusable methods,
   invariants, data structures, and Go techniques.
2. Follow the [interview plan](INTERVIEW_PREP_PLAN.md) when preparing
   for a timed interview cycle.
3. Solve one active exercise in the [workbench](workbench/README.md).
4. Use the [problem index](problems/README.md) for standalone practice
   and reviewed solutions.

## Directory map

- `CONCEPTS.md` owns reusable DSA teaching material.
- `CONCEPTS_STANDARDS.md` defines the teaching-entry contract.
- `workbench/` owns the active exercise.
- `problems/` owns unsolved practice and completed solutions.
- `internal/` owns DSA-specific runners and validation tools.

Run commands from the repository root. The complete validation
sequence is documented in [`../VALIDATION.md`](../VALIDATION.md).
