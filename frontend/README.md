# Frontend Engineering Curriculum

This is the primary web-engineering track. It targets senior frontend
roles first and preserves a direct route into full-stack work.

Every numbered lesson is grouped in the single
[frontend concept guide](CONCEPTS.md) and follows the shared
[concept study standards](../CONCEPTS_STANDARDS.md).

## Foundations

1. [Semantic interfaces and accessibility][interfaces]
2. [JavaScript language and the browser runtime][runtime]
3. [TypeScript type modeling and runtime boundaries][typescript]
4. [HTTP, caching, and network delivery][network]
5. [Browser storage, origins, and security][security]
6. [CSS, layout, responsive design, and rendering][css]
7. [Modules, toolchains, and production builds][toolchain]

## Product application engineering

8. [React components, state, and effects][react]
9. [Server data, routing, caching, and forms][data]
10. [Testing, performance, and frontend observability][quality]
11. [Rendering architectures, hydration, and Server Components][rendering]

## Senior engineering

12. [Frontend architecture and design systems][architecture]
13. [Delivery, migrations, and technical leadership][leadership]

## Application preparation

- Use the repository's [senior frontend preparation plan][job-plan].
- Use [frontend capstone evidence][capstone] to demonstrate depth.
- Use the [algorithm guide][algorithms] for coding interviews.
- Add the [backend extension][backend] when full-stack roles are
  attractive or frontend openings are limited.

## Study rule

Do not mark a lesson complete after reading it. Reproduce its trace,
implement its example, trigger its failure case, pass its checks, and
explain its tradeoffs aloud.
